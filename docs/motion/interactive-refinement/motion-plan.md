# Section motion direction

Use the same original assets, palette and saved content. Each section gets one distinct primary motion. Avoid repeating fade-up on every heading, row and card.

| Section | Choreography | Status |
| --- | --- | --- |
| Hero | Opposing horizontal text masks; center-out photo reveal; copy clears before portrait expansion | Built |
| Stack | Two compact outlined chip belts traveling in opposite directions | Built |
| Projects | Drag-driven horizontal cards with spring settling and scale/opacity depth | Built |
| About | Existing scroll word emphasis; remove secondary movement in a later pass | Existing |
| Experience | Existing growing timeline with progress-led rows; dates remain anchored | Existing |
| Education | Reveal the credential horizontally behind a mask; date and institution remain fixed; remove vertical drift | Proposed |
| Training | Rows draw their dividers in sequence; disclosure content opens with measured height; arrow rotates only on opening | Proposed |
| Contact | One horizontal heading reveal on entry; contact links stay fixed; no looping motion on email or AI tools | Proposed |

Hero timing: opposing type reveal 0.95s; portrait reveal 1.1s. Carousel uses a damped spring rather than a repeating entrance effect. Motion slows into its resting state and interaction stays immediate. On phone, retain compact chips and swipeable cards; omit the pinned portrait expansion. Respect the device's reduced-motion setting throughout.
